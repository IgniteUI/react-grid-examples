# New Fleet Management

Standalone Ignite UI for React sample. A master-detail grid for managing vehicle acquisition, operations, and maintenance: status filters, search, row actions, a reset with confirmation, light and dark appearances, three component sizes, and per-vehicle details with trip, maintenance, cost and utilization views.

## Run locally

1. Install dependencies:
   npm install
2. Start development server:
   npm start

## Build

npm run build
