# New Financial Portfolio

Standalone Ignite UI for React sample. Asset tracking with profit and loss analysis and interactive dynamic charts: a holdings grid marked to a simulated live market, with flashing price changes, per-row price trend sparklines, the holding period against the one-year long-term line, each position's share of the portfolio, an asset filter that highlights its matches, column hiding, pinning and export, and light and dark appearances.

## Run locally

1. Install dependencies:
   npm install
2. Start development server:
   npm start

## Build

npm run build
