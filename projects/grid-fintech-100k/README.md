# FinTech 100K

Standalone Ignite UI for React sample. A 100,000-row, 41-column instrument grid with Excel-style filtering, sorting, column moving, pinning and hiding, row selection and cell editing, and export to Excel and PDF. The toolbar switches the grid between small, medium and large sizes and between light and dark appearances.

The rows are generated in the browser when the grid first renders: random instruments, regions, contracts and dates, with a random price move on each. Reloading the page generates a new set.

## Run locally

1. Install dependencies:
   npm install
2. Start development server:
   npm start

## Build

npm run build
