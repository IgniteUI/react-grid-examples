# FinTech Dock Manager

Standalone Ignite UI for React sample. A trading desk in a Dock Manager: a watchlist, an order ticket, positions and order blotter grids, financial charts, a news wire and a live market feed (a SignalR hub, with a simulated feed when the hub is out of reach).

## Run locally

1. Install dependencies:
   npm install
2. Start development server:
   npm start

## Build

npm run build
